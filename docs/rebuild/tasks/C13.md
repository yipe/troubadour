## Build
`overview.generate(vault, sessions, timeline, numbers) -> dict[str, str]` (path → Markdown), written to `_Overview/` in
the vault right before each backup scan:
- `_Overview/Campaign overview.md`: the last session (title linked to its page, its summary), the party (PCs with class, player), and recently learned (the 10 newest confirmed facts with sources, each linking its entry).
- `_Overview/Session log.md`: every written-up session, newest first: `S<n> · date · [[page|title]]` + summary.
- `_Overview/People and places.md`: NPCs, Places and Factions with their descriptions, linked.
- `_Overview/Facts by session.md`: confirmed facts grouped under their source session.
- `_Overview/The journey.md`: per session, its places in order (from the timeline).
- Rules: **confirmed facts and written-up sessions only** (nothing suggested). Each file starts with a front-matter key `troubadour: generated` and a line saying it's rebuilt on every backup. Write only when the content changed (so unchanged pages don't count as changes). Never write outside `_Overview/`. Never touch a file there that lacks the generated marker (the user's own file): log and skip it.
- `Vault` ignores `_Overview/` (check that its folder scan does; add a test). Ask ignores it too (C14 owns that change; if C14 has merged, check it).

## Tests (`test_overview.py`)
Each page from a fixture vault; suggested facts never appear; an unchanged page isn't rewritten (mtime); a user file without the marker is left alone; a backup run generates the pages before scanning (MockTransport plan request includes them).
