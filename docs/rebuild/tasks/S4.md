## Build
- `TranscriptLine`: `{ line: ViewLine, highlighted?, onTimestamp?(line), onSpeakerClick?(line, anchor), aside? }` where `ViewLine = { id, t, speaker: { name, color, as? } | null, label?: string /* "Voice 3" */, text, fixes, unsure? }`. Grid: 64px timestamp column (mono 12px `ink-subtle`, clickable when `onTimestamp`), then **name** (bold, colour) + "as X" note + text (15px, line-height 1.55). Unnamed voices: label + text in italic `ink-subtle`. `highlighted` = `bg-accent-soft` + inset ring `accent-strong` + `animate-flash`. `FixedText` (moved here from legacy) underlines fixed spans with the title "Heard as …".
- `TranscriptList`: `{ lines, mode: "live"|"static", highlightId?, scrollToId?, renderAside?(line), asideWidth = 460, footer? }`. Virtuoso. In live mode it follows the bottom while the user is at the bottom, and shows a "Jump to latest" button otherwise (port the old behaviour). `scrollToId` scrolls to that line and centres it. With `renderAside`, each row is `grid-cols-[1fr_<asideWidth>px]` so the aside sits on the same row as its line. `footer` renders after the last row (the "X is speaking…" line).
- `toViewLines(messages, voices, players)` and `recordToViewLines(record)` helpers here (they're only used with these components). They use `speakerFor` from S2.

## Tests
- Port the `ChatFeed` tests (follow-bottom, jump-to-latest), replacing Virtuoso with a plain list the way the old test did.
- `scrollToId` calls `scrollToIndex` with the right index; `highlightId` sets `aria-current` on that row.
- `renderAside` content renders in the same row element as its line.
