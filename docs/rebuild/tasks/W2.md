# W2 · Headless screenshot + route smoke tool

**Deps:** W1, B4 · **Size:** S · **Owns:** `web/app/scripts/`

## Read first
- `scripts/scratch.sh` (P0), `docs/rebuild/README.md` → *Safety*.

## Goal
Two scripts every UI task and X3 use. Both drive Chromium **headless with `--mute-audio`**, against a scratch
server, at 1440×900 (the design's canvas).

## `web/app/scripts/shot.ts`
`pnpm -C web/app shot <route> <out.png> [--port 8770] [--wait <css selector>] [--full]`
- Opens `http://127.0.0.1:<port><route>`. Port defaults to `$PORT`, then 8767. It refuses 8765.
- Waits for `networkidle`, then for the optional selector, then 300 ms.
- Writes a PNG. Prints console errors and failed requests to stderr. Exit code 1 if there were any page errors.

## `web/app/scripts/smoke.ts`
`pnpm -C web/app smoke [--port 8770] [--out /tmp/smoke]`
- Visits a fixed list of routes (`/`, `/sessions`, `/sessions/new`, `/sessions/<newest id>`, `/sessions/<id>/review`, `/sessions/<id>/transcript`, `/sessions/<id>/recap`, `/timeline`, `/codex`, `/codex/Captain Orsa Vell`, `/facts`, `/ask`, `/settings/models`, `/settings/microphone`, `/settings/players`, `/settings/vault`, `/settings/cloud`, `/welcome/campaign`). It gets the newest session id from `GET /api/sessions`.
- For each route: screenshot to `<out>/<slug>.png`, collect console errors, page errors and HTTP ≥ 400 responses (except ones a route expects; keep an allow-list in the file and justify each entry in a comment).
- Prints a table; exit 1 on any failure.
- It never clicks Start, never opens a mic test, never plays audio.

## Acceptance
- With `scripts/scratch.sh 8770` running: `pnpm -C web/app shot / /tmp/w2.png --port 8770` writes a non-empty PNG (W1's placeholder page is fine).
- `pnpm -C web/app smoke --port 8770` runs and reports every route. Failures are expected until the pages exist; check that they show up in the table.
- `pnpm -C web/app shot / /tmp/x.png --port 8765` exits non-zero without opening a browser.
