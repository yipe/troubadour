## Build (`pages/welcome/`, bare layout)
- Header: "Troubadour" wordmark + "New campaign"; right: "Saved as you go · Finish later" (→ `/`).
- Left rail (300px): page-local `StepRail` of 5 `NavItem`s with 24px numbered circles (done = success ✓, current = `accent-strong`, upcoming = `line-strong` ring) and a sub line, plus the footer note with a lock: "Everything here stays on this Mac unless you choose a hosted model in step 5."
- Main (padding 36×56): "STEP N OF 5", serif 30px H1, an explainer, the step body, and the footer: Back / "Continue to <next> →".
  1. `campaign`: campaign name; vault: "New vault folder" (default) or "Use an existing folder" (path input; the API adopts it). Creates a campaign or, when the open one is empty (no sessions), renames it. `?new=1` always creates.
  2. `table`: "Who's at the table?" + `PlayersTable mode="wizard"` + the info note "The player colour comes from their class…".
  3. `microphone`: `MicCard mode="wizard"`.
  4. `notes`: `ImportNotes` + "Skip".
  5. `privacy`: `ModelsSettings`. "Finish" → `/`.
- Each step saves immediately, so reloading mid-wizard resumes at the URL's step. The rail lets you jump back to finished steps.

## Tests
Step navigation and rail states; step 1 creates (or renames the empty campaign); `?new=1` always creates; Finish goes home.
