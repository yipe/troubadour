**Deps:** X2 · **Size:** M · **Owns:** `docs/rebuild/REPORT.md`

## Steps
1. `scripts/scratch.sh 8790`, then `pnpm -C web/app smoke --port 8790 --out /tmp/x3`. Every route passes with no console errors.
2. For each design screen in `page-map.md`, put the smoke screenshot next to the design PNG and record the differences in `REPORT.md` (screen · matches / minor / off · notes).
3. Audit and record findings (don't fix them here):
   - **Rule of two:** shared components with one user, and page-local components duplicated across pages.
   - Server data in zustand, `fetch` outside `@troubadour/api`, campaign writes outside `campaignWrite`, raw hex in components, `style` colours other than player or class variables.
   - Python: modules over 600 lines, layer-contract exceptions, pydantic models without caps, LLM output written without validation.
   - Dead code: unused exports (`pnpm dlx knip` on the web workspace; report, don't add deps).
   - **Conventions** (`docs/conventions.md`): default exports, string-literal URLs instead of `paths.*`, `os.environ` outside `config`, files over the size guide, hand-written API types where a `response_model` exists, `toLocale*` with `undefined`, sleeps in tests.
   - The basedpyright baseline size before and after the rebuild (it should only shrink).
4. With the owner, not autonomously: replay a seeded session on a scratch server with the real local LLM (`scripts/scratch.sh 8790 --llm`) to watch notebook items arrive and do a write-up → review → recap round trip.
5. End `REPORT.md` with a fix list, each item small enough for one Sonnet task.
