**Deps:** W1 · **Size:** L · **Owns:** `web/packages/api/src/`

## Read first
- `architecture.md` → *Web packages* (`@troubadour/api` layout).
- Old: `web/legacy/src/lib/types.ts` (the contract), `lib/api.ts` (about 85 endpoints), `test/mockFetch.ts`, `test/fixtures.ts`.

## Goal
Port the contract and every HTTP call, split by domain, with no behaviour change. Create the empty domain
folders the C-tasks will fill.

## Layout (`src/`)
```
http/index.ts       req<T>(method, path, body?) (JSON; 204/202 -> undefined; non-OK -> ApiError(status, detail)), ApiError, url helpers
events/index.ts     ServerEvent union (all 22 types today), imports payload types from domains
players/            types.ts (Player, LibraryPlayer, TrainStatus), endpoints.ts, index.ts
campaigns/          CampaignInfo, Campaigns; create, rename, open
session/            Session, Source, SourceList, Voice, Message, Fix, MessagePatch, Snapshot; start/pause/resume/stop, sources, voices/messages assign, recheckLlm, transcriptUrl
sessions/           SavedSession, SessionRecord, Record*, Improved/Retranscribed/InCharacter/SpellingInfo, RecordingQuality; list, merge, record, improve, retranscribe, spelling, inCharacter, restore, quality, sessionAudioUrl

ask/                AnswerSource, CampaignAnswer; ask
cloud/              CloudStatus, CloudBackup, CloudAccount, CloudVault; status, connect, disconnect, options, backup, vaults, account, restore
llm/                LlmProviderId, LlmProvider, ModelSettings, LlmModel; settings, localServers, scanLocalModels, models, connect, key, disconnect
audio/              AudioLevel, LevelZone, AudioQuality, Grade, QualityGrades, QualityNumbers, QualityVerdict, MicInfo, MicSpecs, MicCheck…; mics, updateMic, startMicTest, stopMicTest, setAudioMonitor

```
Each domain `index.ts` re-exports its `types` and `endpoints` (and, after A3, `queries`). Consumers import
`@troubadour/api/campaign`. **No root barrel.**

## Rules
- Types are copied from `types.ts` **unchanged**, comments included: they document the contract. Fix only what the split forces (imports). One planned exception: add `"recap"` to `CampaignJob.kind` now (comment: `/* C10: a session recap */`), so C10 doesn't need to edit the campaign domain.
- Endpoint functions keep the old names and signatures, grouped as plain exported functions (`export function createEntity(...)`), not an `api` object.
- URLs used outside `api.ts` before (`/api/files/…`, server-sent `sample_url`s) get a helper in the right domain (`audio.fileUrl(name)`).
- Delete the orphaned comment blocks the inventory found in the old `api.ts`; don't port them.

## Tests
- `http`: a non-OK JSON response with `detail` becomes `ApiError(status, detail)`; 204 returns `undefined`; the body is sent as JSON with the right header.
- `testing/mockFetch`: records calls and routes them by method + path.
- One smoke test per domain: call one endpoint through `mockFetch` and check method, path and body.

## Acceptance
- `pnpm -C web/packages/api test typecheck` pass; `pnpm -C web lint` passes.
- Every function in the old `api.ts` exists in exactly one domain (write the mapping in your report: old name → domain).
