## Build
- `RailLayout`: `{ rail, railWidth = 300, children, aside?, asideWidth = 300 }`. Full-height flex. The rail has `border-r border-line`; the aside has `border-l` and `bg-sunken`. Each column scrolls on its own (`min-h-0 overflow-auto`).
- `NavItem`: a button or link (`render` prop for router links). `selected` = `bg-surface` + `inset 0 0 0 1px accent-strong`, `rounded-control`, padding 8–10px 12px. Slots: `icon`, `sub` (second line), `count` (right, mono-ish 12px), `dot` (tone).
- `UnderlineTabs`: `{ items: {id,label,count?,dot?}[], value, onChange, size: "nav"|"panel" }`. Active: `ink`, 600, 2px `accent-strong` underline; inactive `ink-subtle`. Renders links when items carry `href`; for the top nav, use a `renderItem` prop.
- `PillGroup`: single-select pills with counts (`All 9 · Facts 4 · …`). Active = `bg-accent-strong text-ink-on-accent`.
- `SegmentedBar`: `{ segments: {value, color, label}[], height = 8, gap = 2 }`, widths proportional, `rounded-full` ends, `aria-label` listing the shares. `SegmentedLegend`: dot + label + percent.
- `Chip`: `{ tone, dashed?, onClick?, onRemove?, children }`. The dashed variant is the pending heard-as chip, with ✓/✕ buttons through `onAccept`/`onReject`.
- `Table`, `THead`, `TH` (serif, 13px, `ink-muted`), `TR` (zebra via `even:bg-sunken/40`), `TD`. Plain `<table>` elements; no data-table abstraction.
- `Progress`: `{ value: 0..1, tone }`, 4–6px.
- `EmptyState`, `IconTile` (28–36px rounded square, `bg-elevated` or a tone's soft background, centred icon).
- `gallery/sections/layout.tsx`.

## Tests (`layout.test.tsx`)
- `SegmentedBar` widths are proportional (3 segments 2/1/1 → 50%/25%/25% within rounding), and zero total renders nothing.
- `UnderlineTabs` calls `onChange` with the id and marks the active tab `aria-selected`.
- `PillGroup` shows counts and selects one item.
