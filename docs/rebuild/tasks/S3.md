## Build
- `people/PlayerAvatar.tsx`: `{ player?: Player | RecordPlayer, name?, color?, size }` → `Avatar` with `playerColor`, initials, or the player's avatar image.
- `people/SpeakerName.tsx`: `{ name, color, as? }` → bold name in the colour, then "as <character>" in `ink-subtle` 13px.
- `people/TalkShareBar.tsx`: `{ talk, players, legend = true, height }` → `SegmentedBar` + `SegmentedLegend` from `talkSegments`.
- `entity/ConfidenceBadge.tsx`, `entity/TypeBadge.tsx` (NPC, Place, Item…; `TYPE_LABEL`), `entity/EntityLink.tsx` (`{ name, type? }` → link to `/codex/<name>`, items in `text-legendary`, an unknown name as plain text), `entity/FactText.tsx` (renders `[[Target]]` / `[[Target|label]]` as `EntityLink`s via `splitWikiLinks`).
- `audio/SessionAudioProvider.tsx` + `useSessionAudio()`: **one** shared `<audio preload="none">`. `play(sessionId, t)` sets the src (`sessionAudioUrl(id)`), seeks, and plays. It is called only from a click handler. `stop()`. It exposes `{ playing: {sessionId, t} | null }`. S1 created this file as a passthrough and already mounts it in `App.tsx`; replace its body.
- `audio/TimestampLink.tsx`: `{ sessionId, t, label?, hasAudio, onJump? }` → mono 12px `text-accent` button with a play icon. Click: `onJump?.(t)`; if `hasAudio`, `play(sessionId, t)`; otherwise navigate to `/sessions/<id>/transcript?t=<t>`. Shown as "S12 · 1:41:55" when given `n`.

## Tests
- `TimestampLink` never plays on render; a click plays when there's audio and navigates when there isn't.
- `FactText` turns `[[Orsa Vell|the captain]]` into a link labelled "the captain" to `/codex/Orsa Vell`.
- `PlayerAvatar` uses the class colour for a player with `dnd_class` and no override.
