# B4 · Demo seed: a scratch data dir with The Sunken Crown

**Deps:** B1 · **Size:** M · **Owns:** `backend/spike/seed/`, `backend/spike/seed_demo.py`

## Read first
- `docs/design/troubadour-redesign/data.js`: the mock campaign (players, lines, facts). Made-up names; fine to use.
- `docs/design/troubadour-redesign/README.md` → *Screens* for what each screen shows.
- Code that defines the on-disk formats: `troubadour.engine` state (`state.json`, STATE_VERSION 2), `troubadour.core.transcript.build` (saved records), session `meta.json`, `troubadour.lore.campaign.Vault` (entity notes), and the write-up page format (`lore/memory.py`, `lore/writeup.py`).

## Goal
`uv run python spike/seed_demo.py <data_dir>` builds a complete, realistic data dir in about a second, with no
models, no LLM and no network. Every UI task screenshots against it.

## Contents
- **Players** (seated in campaign "The Sunken Crown"): Alex (GM), Sam / Pip Tallowmere (bard), Jo / Thessaly (druid), Rin / Brann Coldwater (barbarian), Maya / Velis Anwe (wizard, untrained). One library player in a second campaign "Lantern Road". Voices for the four trained players (any small fake embedding the loader accepts; read `_load_state` to see what it needs).
- **12 saved sessions**, S1…S12, weekly from Sep 3 to Oct 22 (2026), 2.5–3.5 h each. Titles from the 4a screenshot (S12 "The Drowned Abbey", S11 "Bells of Saltreach", S10 "Debts and Riddles"…). Each has `meta.json` and `transcript.json` with 60–200 lines drawn from `data.js` plus generated filler. Lines must use realistic `t_start` values across the session, speakers mapped to players, some `Voice N` lines, and some `fixes`. No audio files: `audio: false`.
- **Write-ups** for S1–S11 (S7 left "not written up"): session pages in the vault's `Sessions/` folder with title and wrap-up, and `written_up` pointing at them.
- **Vault**: about 25 entries across NPC/Place/Item/Faction/PC (Captain Orsa Vell, The Abbot, Diamond of Ysolde, The Tidecallers, Drowned Abbey, Saltreach, Gull's Debt, Sister Merrow…), with descriptions, aliases, heard-as (some suggested), facts, a few suggested facts, and two suggested entries ("The Abbot", "Choir voice").
- Write everything through the real writers (`Vault`, `transcript.build`, the engine's state writer if it's a free function) wherever you can, so formats stay correct as code changes. Write JSON by hand only where no writer exists.

## Structure
```
spike/seed_demo.py         main(data_dir): wipe-safe check, then call each module in order
spike/seed/__init__.py
spike/seed/common.py       dates, ids, deterministic RNG (seeded; output identical every run)
spike/seed/players.py      players, voices, campaigns, state.json        (C1 extends: classes)
spike/seed/sessions.py     sessions, records, meta                       (C2, C7 extend)
spike/seed/vault.py        entries, facts, write-up pages                (C6, C7 extend)
spike/seed/notebook.py     empty function seed(ctx) -> None              (C3 fills)
```
Each module exposes `seed(ctx: SeedContext) -> None`. `SeedContext` is a dataclass with `data_dir`, `vault_dir`, `campaign_id`, `players` and `sessions`. Modules must not import `troubadour.engine` or `troubadour.server`, which change shape in B2 and B3. Use `troubadour.core` and `troubadour.lore` only.

## Safety
`seed_demo.py` refuses (exit 2) when `data_dir` resolves inside `~/troubador` or is not empty and has no `.troubadour-seed` marker file. It writes the marker first.

## Acceptance
- `cd backend && uv run python spike/seed_demo.py /tmp/seed-check && ls /tmp/seed-check/sessions | wc -l` prints 12.
- Running it twice into a dir with the marker gives byte-identical output (`diff -r`).
- `scripts/scratch.sh 8770`: `curl -s 127.0.0.1:8770/api/sessions` lists 12 sessions; `/api/campaign` lists the entries; `/api/state` shows 5 seated players.
- `uv run ruff check spike` passes.
