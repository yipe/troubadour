# B2 · Split the engine module into focused modules

**Deps:** B1 · **Size:** L · **Owns:** `backend/packages/engine/src/troubadour/engine/`, `backend/tests/`

## Read first
- `backend/AGENTS.md` → *Invariants* (session isolation, locks).
- `architecture.md` → *Decisions* #2 (mixins now, composition later).
- `engine/live.py` (the old 2.4k-line engine.py).

## Goal
Small modules with one job each. The public API stays identical: `from troubadour.engine import Engine, …`
works as before, and server and test call sites don't change (string monkeypatch targets excepted). No
behaviour change, except the `TROUBADOUR_MODELS=0` switch in step 4.

Mixins hold no state of their own. All state stays on `Engine`, created in `Engine.__init__`. Each mixin
module starts with a docstring naming the `Engine` attributes it reads and writes, and the lock that guards
them.

## Steps
1. Move code verbatim. Don't rename, reorder logic or "improve" anything.
2. **Monkeypatched globals.** Tests patch these on the engine module: `SETTLE_S`, `MIC_STALL_S`,
   `GLOSSARY_CHECK_S`, `IDLE_POLL_S`, `keep_awake`, `speech_spans`, `subprocess.Popen`, `shutil.which`,
   `MicSource.start`, `MicSource.native_rate`, `FileSource.start`. Each one must live in, or be imported
   into, **the module whose code reads it**. Each test's patch target must name that module, e.g.
   `"troubadour.engine._pipeline.MIC_STALL_S"`. For `engine_module` fixtures that patch through
   `import troubadour.engine as engine_module`, update them to the right submodule.
3. Keep `improve.py`, `cloning.py` and `sim.py` working: they import from `troubadour.engine`, so the re-exports cover them.
4. **`TROUBADOUR_MODELS=0`**: in `core.py`'s model loading, `if config.env("MODELS", "1") == "0"` skips loading Whisper, the embedder and VAD. `asr.state` stays `"loading"` and an INFO log says why. This lets scratch servers run many at once without loading models. Test: with the env set, `start_background()` returns without touching `troubadour.sound.asr` (patch it to raise).
5. Delete `live.py` when it's empty.

## Edge cases
- Class attributes or module constants referenced as `Engine.X` elsewhere: keep them reachable.
- Circular imports between mixins: mixins must not import each other. They call through `self`.
- Thread targets like `target=self._segment_loop` keep working through inheritance. Check that no test patches `Engine._segment_loop` on the class with a module path.

## Acceptance
- `cd backend && uv run pytest` is green with the same test count as before.
- No module in `troubadour/engine/` is over 600 lines (`wc -l`).
- `uv run lint-imports` and ruff pass.
- `git grep -n '"troubadour.engine\.[A-Za-z_]*"' backend/tests` lists only targets that exist as module globals where they're used. Report the list.
