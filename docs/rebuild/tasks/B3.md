# B3 · Split the server into routers + dependency module

**Deps:** B2 · **Size:** L · **Owns:** `backend/packages/server/src/troubadour/server/`, `backend/tests/`

## Read first
- `backend/AGENTS.md` → *Adding an API endpoint*.
- `server/app.py` (the old server.py, about 1.3k lines, about 72 routes).

## Goal
One FastAPI `APIRouter` per domain, singletons in one module, the app wired in `app.py`. Same URLs, same
payloads, same middleware. Empty routers for the endpoints coming in C-tasks, so those tasks never touch
`app.py`.

## Target (`troubadour/server/`)
| Module | Contents |
|---|---|
| `deps.py` | the module-level singletons, created exactly as today: `bus`, `engine`, `vault`, `memory`, `cloning`, `asker`, `cloud`, `accounts`, `campaign_gate`, plus `_call`, `_recheck_llm_soon`, `_installed_llms`, `LOCAL_HOSTS`. Routers use `from troubadour.server import deps` and call `deps.engine…`. Never `from .deps import engine`: that copies the object, and tests that patch `deps.engine` would miss it. |

Pydantic input models move into the router that uses them. A model used by two routers goes in `models.py`.

## Steps
1. Move handlers verbatim. Route order matters for overlapping paths (`/api/players/{pid}/clone` vs `/api/players/{pid}`): keep the same relative order. Check by diffing `[(r.path, sorted(r.methods)) for r in app.routes]` before and after; save the "before" list from the old module first.
2. Tests patch `server.engine`, `server.memory`, `server.asker`, `server.cloud`, `server.accounts`, `server.bus`, `server._recheck_llm_soon`, `server.httpx`, `server.list_mics`, `server._installed_llms`. Point them at `deps` (or, for `httpx` and `list_mics`, at the router module that calls them). Tests that use `server.app` import `from troubadour.server.app import app`.
3. A `tests/test_routes.py` that pins the full route list (method and path) against a literal list in the test. This catches dropped routes now and makes later additions explicit.

## Acceptance
- `uv run pytest` is green; the route list before and after is identical (paste the diff command and its empty output in your report).
- `app.py` is under 120 lines; every router module is under 400.
- `scripts/scratch.sh 8770`: `/api/state`, `/api/campaign`, `/api/sessions` and `/` (index.html) all answer.
