# F34 · Imported notes backfill "The story so far"

**Deps:** F33 merged (Timeline who-talked changes) · **Priority:** medium · **Size:** M (about half a day)

Owner request (2026-10-30): "If I ingest notes with clear session names, can they fit into 'the story so
far' as backfill? And not just backfill terms and stuff."

Today `Memory.import_notes` (`lore/memory.py:670`) saves the paste verbatim as `Notes/<title>.md` and runs an
LLM pass that adds entities and facts. The Timeline (`lore/timeline.py`, `server/routers/timeline.py`,
`web/app/src/pages/timeline/`) only lists saved sessions (folders under `sessions/` with `meta.json`), so
imported notes never show up there.

## Goal
Notes pasted with clear session headings become **notes-only sessions**. They appear on the Timeline in date
order and are numbered with the recorded sessions. Their facts and new faces count toward their own row.

## Design
1. **Split (pure function, no LLM):** `lore/notes_split.py` `split_sessions(text) -> list[NotesSession]`
   with `n | None`, `date | None`, `title | None`, `text`. Recognize Markdown headings (`#` to `###`) or
   lines on their own like "Session 3", "S3 - Oct 2", "Session 12: The Drowned Abbey", "2026-09-14",
   "Sept 14, 2026". A split is only "clear" with **at least 2** session headings. Otherwise return `[]`,
   and the import behaves exactly as today. Text before the first heading stays with the whole-notes import.
   Put the cases in `shared/test-vectors/notes-split.json` (Python tests only for now; the client doesn't split).
2. **Preview:** `POST /api/campaign/import/preview {title, text}` returns the split (n, date, title,
   first 200 characters). It's a pure function, so this isn't a background job. In `ImportNotes`, when the
   preview finds sessions, show them as a list: "Found 6 sessions. They'll appear on the Timeline." It
   offers a checkbox for "Add them to the Timeline" (on by default), and each row's date and title can be
   edited. A missing date must be filled in before importing, or the row is unchecked.
3. **Notes-only session on disk:** for each checked row, create `sessions/<id>/` where `<id>` follows the
   usual `YYYY-MM-DD_HHMMSS-xxxx` format, using the given date at 12:00 local time plus a random suffix.
   Never reuse or overwrite an existing folder. Write:
   - `meta.json` with `{"kind": "notes", "campaign": <open campaign>, "started_at": <date epoch>,
     "title": ..., "note": "Notes/<page>.md", "duration": 0, "pipeline": {}}`
   - no `transcript.json` and no `audio.wav`
   - a vault page per session, `Notes/<title>.md`, with the session's text (same front matter as today,
     plus `session: <id>`), so `session_page` gives the Timeline its title and summary.
   Then run the existing `_merge_notes` LLM pass **per session**, with `Source` pointing at that session's
   page, so its facts and new entities are credited to that session.
4. **Numbering:** `session_numbers` already sorts by `started_at`, so notes sessions number in date order.
   Add vectors where notes sessions predate and interleave with recorded ones. Check that the shared vectors
   still pass on both sides.
5. **Timeline:** `timeline()` includes notes sessions. `session_mentions` returns empty mentions when there's
   no `transcript.json`. Instead, count names in the session's notes page, so the Codex mention dots work
   too. The row carries `kind: "notes"`. On the web, the who-talked cell shows a muted "From notes" label
   instead of the bar (no talk data). "Where" uses places from the notes page if the existing fallback
   finds them.
6. **Everything that expects audio or a transcript skips notes sessions:**
   - Improve, retranscribe, spelling, in-character, refresh and upgrade all return 409 with a clear message.
   - Pipeline stamping doesn't treat them as out of date.
   - The quality check and replay don't run.
   - The live "newest session is the current one" rule ignores them (`web/AGENTS.md` gotcha).
   - Sessions list and detail show a "Notes" badge and the notes text instead of the player.
   - Delete and undelete work (move to `.trash`). Merge refuses a notes session (409) for now.
   - Ask and recap may read the notes page as that session's text if that's a small change. Otherwise
     leave a note in `docs/rebuild/NOTES.md`.
7. **Safety:**
   - The import never overwrites a note or a session folder. Name clashes get a suffix, the same as
     `write_note`.
   - Importing the same paste twice creates nothing new. Fingerprint each session's text (sha256) in its
     `meta.json` and skip any that match an existing notes session in the campaign.
   - Validate at the edge: at most 50 sessions per import, titles at most 120 characters, dates within
     1970 to 2100.
