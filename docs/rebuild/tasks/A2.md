# A2 · WebSocket client + live-session store

**Deps:** A1 · **Size:** M · **Owns:** `web/packages/api/src/socket/`, `web/packages/api/src/live/`

## Read first
- Old: `web/legacy/src/lib/store.ts` (connect, applyEvent, snapshot handling, `useSpeaking`), `lib/audio.ts` (level pub/sub, quality), `lib/store.test.ts`, `lib/useSessionTime.ts`.
- `web/AGENTS.md` → *Rules* (the live store holds only the live session; `messages.updated` patch semantics; UTF-16 fixes).

## Build
- `socket/index.ts`: `createSocket({ url? })` returns `{ connect(), close(), on(type, handler) -> unsubscribe, onAny(handler), connected: () => boolean, onStatus(cb) }`. JSON frames `{type, data}`. Reconnect with backoff starting at 500 ms, doubling to a 5000 ms cap, reset after a successful open. Exactly one instance per app (S1 creates it). The default URL is `ws(s)://<location.host>/ws`.
- `live/store.ts`: a zustand store for **only** the running session: `connected`, `loaded`, `session`, `sessionAt`, `players`, `library`, `voices`, `messages` (ordered, with the id→index cache), `bumps`, `train`, `focus`. `applyEvent(ev)` ports the old logic for `snapshot`, `session.updated`, `player.*`, `library.updated`, `voice.*`, `message.created`, `messages.updated`, `train.status` and `error` (the error goes to an `onError` callback, not a toast import). It ignores the other event types; A3's bridge handles them. Port the binary-search ordered insert and the patch rules exactly.
- `live/speaking.ts`: the `useSpeaking` store (`speaker.active`, auto-clear after 1.5 s), kept separate so its ~4 Hz updates don't re-render the transcript.
- `live/audio.ts`: port `lib/audio.ts` (level pub/sub with `subscribeLevel`, `currentLevel`, quality state, `mic.test` state, zone helpers).
- `live/hooks.ts`: `useLive(selector)`, `useSessionTime()` (port), `useIdle()`.
- `live/index.ts`: `wireLive(socket)` subscribes the store, speaking and audio to the socket and returns an unsubscribe. A `resetLive()` for tests.

## Tests (port and extend `store.test.ts`)
- Snapshot replaces everything; `message.created` keeps order for out-of-order ids; `messages.updated` replaces `text` and `fixes` wholesale and ignores unknown ids; `voice.removed` with `merged_into` relabels.
- Socket: reconnects with backoff (fake timers + a fake WebSocket class), handlers get typed data, unsubscribe works.
