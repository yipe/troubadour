## Build
1. **Device name**: `scutil --get ComputerName` (macOS), else `socket.gethostname()`, cached. The commit `message` becomes `"<device> · <summary>"` (≤ 200 chars, per the contract).
2. **Main device**: `status()` adds `device`, `main_device` and `is_main`. With `last_backup.snapshot` known, compare it with the vault's `head_snapshot` (from `GET /vaults`, cached 60 s). If they're equal, or there's no head, this Mac is main. If not, read the head snapshot (`GET /vaults/{id}/snapshots/{head}` → its `snapshot.message`, when present) and take the device before `" · "`; otherwise "another Mac". A backup from this Mac makes it main again: newest backup wins. Never block `status()` on the network for more than 3 s; on error, keep the last known values.
3. **Pause while live**: `AutoBackup` takes an `is_live: Callable[[], bool]` (wired in `deps.py` to the engine session status). While it's true, scheduled backups wait and `status.paused_live = true`. When the session ends, run the pending backup. "Back up now" while live → 409 with "Backups wait until the session ends."
4. **History**: every attempt (auto or manual, success or failure) is appended to `DATA_DIR/cloud_history.json` per campaign: `{at, ok, snapshot, files, changed, message, error}`, kept for 90 days. `GET /api/cloud/history` → `{attempts}` (newest first).
5. **Restore point**: `POST /api/cloud/restore {vault_id, snapshot?}` restores that snapshot (a successful attempt's id) instead of the head. Same safety as today: files that differ move to `.trash/`.

## Contract rule
Every endpoint you add or change declares a pydantic `response_model` (payload shapes as classes in the router, or in `server/models.py` when two routers share one). In `@troubadour/api`, its types are `Schemas["<Model>"]` from `../generated` (the B6 recipe), not hand copies. WebSocket payloads reuse the same models. Run `pnpm -C web/packages/api gen` after changing a model.

## Tests (`test_cloud_history.py`, MockTransport)
The message carries the device; another device's head → `is_main` false with its name, and our next backup → true; while live, auto backup waits and manual → 409, then it runs after the session; attempts are logged, failures too, and pruned at 90 days; restore with a snapshot id fetches that snapshot.
