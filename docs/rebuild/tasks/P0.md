# P0 · Design references in docs/, scratch-server script

**Deps:** none · **Size:** S

## Read first
- `docs/rebuild/README.md` (rules)
- The handoff zip: `Troubadour UI Redesign.zip` in the repo root (the owner copied it there), or `/tmp/troubadour-plan/design/` if it was already extracted.

## Goal
The design handoff lives in the repo where every task can read it, and there is one safe way to run a throwaway server.

## Steps
1. Extract the zip's `design_handoff_troubadour_redesign/` folder to `docs/design/troubadour-redesign/`.
2. Commit everything **except** the design-system runtime, which is large, generated, and needed only to open
   the `.dc.html` files in a browser: add `docs/design/troubadour-redesign/_ds/` and
   `docs/design/troubadour-redesign/support.js` to `.gitignore`, but keep the files on disk. Also ignore
   `/Troubadour UI Redesign.zip`.
3. Write `scripts/scratch.sh` (POSIX sh, executable):
   - Usage: `scripts/scratch.sh [PORT] [--keep] [--llm]`. PORT defaults to 8767. It refuses to run with 8765 and exits 2 with a message.
   - `DATA=/tmp/troubadour-scratch-$PORT`. Without `--keep`, delete and recreate it.
   - If `backend/spike/seed_demo.py` exists, run `cd backend && uv run python spike/seed_demo.py "$DATA"` (B4 creates it; until then, skip with a note).
   - Then exec the server with a clean environment for Troubadour:
     `env -u TROUBADOUR_VAULT -u BARD_VAULT TROUBADOUR_DATA="$DATA" TROUBADOUR_PORT="$PORT" TROUBADOUR_SAMPLES="$DATA/samples" TROUBADOUR_OBSIDIAN_REGISTRY="$DATA/obsidian.json" TROUBADOUR_MODELS=0 TROUBADOUR_LLM_URL="${LLM_URL:-http://127.0.0.1:9/v1}" uv run troubadour` (run from `backend/`).
   - `--llm` leaves `TROUBADOUR_LLM_URL` unset, so the local LM Studio is used. The default points at a dead port so nothing reaches a model by accident.
   - `TROUBADOUR_MODELS=0` skips loading Whisper and the voice models (B2 implements it; harmless before).
   - Print the URL and the data dir first.
4. `shared/test-vectors/` with a `README.md` ("Cases both the Python and the TypeScript implementations must pass; edit here, never copy into a test") and two files:
   - `hms.json`: `[[seconds, "h:mm:ss form"], …]` with `[0,"0:00"]`, `[59,"0:59"]`, `[61,"1:01"]`, `[3599,"59:59"]`, `[3600,"1:00:00"]`, `[5882,"1:38:02"]`, `[36000,"10:00:00"]`, `[59.9,"0:59"]` (floor).
   - `session-numbers.json`: `[{ "sessions": [{"id","started_at","merged_from"?}], "expected": {"id": n} }, …]` with: empty list; three sessions out of order; one session merged into another (the absorbed id is listed in the survivor's `merged_from` and gets no number); equal `started_at` (tie broken by id).

## Don't
- Don't put anything but data and the README in `shared/test-vectors/`.
- Don't commit `_ds/`, `support.js` or the zip.
- Don't touch `~/troubador`.

- `sh -n scripts/scratch.sh` passes, and `scripts/scratch.sh 8765` exits 2 without starting anything.
- `scripts/scratch.sh 8767` serves `http://127.0.0.1:8767/api/state` (check with `curl`, then stop it), and `ls /tmp/troubadour-scratch-8767` shows a fresh data dir.
