# B1 · uv workspace: move modules into six packages, layer contract

**Deps:** P0 · **Size:** L · **Owns:** all of `backend/`

## Read first
- `docs/rebuild/architecture.md` → *Layout*, *Backend layering*, the module move table.
- `backend/AGENTS.md`, `backend/pyproject.toml`, `backend/tests/conftest.py`.

## Goal
Same code, same behaviour, new home. `backend/` becomes a uv workspace with six member packages using the
`troubadour.<pkg>` namespace. Tests pass unchanged except for import paths. This is a **mechanical move**: do not
refactor, rename functions, or change behaviour.

## Target
```
backend/pyproject.toml                    virtual workspace root
backend/packages/<pkg>/pyproject.toml     name "troubadour-<pkg>"
backend/packages/<pkg>/src/troubadour/<pkg>/__init__.py    (empty; NO backend/packages/*/src/troubadour/__init__.py)
```
| pkg | modules | runtime deps (move from the root list) |
|---|---|---|
| core | config, settings, providers, transcript, **fsutil (new)** | httpx, pyjwt[crypto] |
| sound | audio, segment, levels, mics, asr, voices, tts | troubadour-core, mlx-whisper, mlx-audio, pyannote-audio, silero-vad, sounddevice, soxr, scipy, numpy (already transitive) |
| lore | campaign, obsidian, memory, writeup (+ writeup_example.md), ask, cleanup, talk, dnd_terms (+ srd_terms.json) | troubadour-core, httpx, pyyaml |
| cloud | backup (= old cloud.py) | troubadour-core, httpx |
| engine | engine (keep as `engine/live.py` for now; B2 splits it) with `engine/__init__.py` re-exporting every name other modules or tests import from `troubadour.engine`; improve, cloning, sim | troubadour-core, troubadour-sound, troubadour-lore |
| server | app (= old server.py), main (= old `troubadour/__init__.py` `main`) | all five above, fastapi, uvicorn[standard] |

## Steps
1. `git mv` each module (keep history). Create the pyprojects with `[build-system] requires = ["uv_build>=0.12.5,<0.13.0"]` and `[tool.uv.build-backend] module-name = "troubadour.<pkg>"`. In the root, set `[tool.uv.workspace] members = ["packages/*"]` and `[tool.uv] package = false`, with a `dependencies` list naming all six members as `{ workspace = true }` sources, so `uv sync` installs everything. Keep the `dev` and `spike` groups at the root and add `import-linter` and `basedpyright` to `dev` (B5 configures basedpyright).
2. Entry points: `troubadour = "troubadour.server.main:main"` (server package), `troubadour-sim = "troubadour.engine.sim:main"` (engine package). In `main`, the uvicorn target becomes `"troubadour.server.app:app"`.
3. Move `write_atomic` from `campaign.py` into `core/fsutil.py`. `campaign.py` imports it from there and keeps exposing it, so `from troubadour.lore.campaign import write_atomic` still works. `tts.py` imports it from `troubadour.core.fsutil`, so sound doesn't depend on lore.
4. Rewrite every import in `src`, `tests` and `spike`: relative imports between packages become absolute (`from troubadour.core import config`). Imports within a package may stay relative.
5. **Fix `config.py` paths.** `BACKEND = Path(__file__).resolve().parents[2]` is now wrong. Find the repo root by walking up from `__file__` to the first directory that contains `backend/pyproject.toml`; `BACKEND = REPO / "backend"`. `WEB_DIST` stays `REPO / "web" / "dist"`. Add a test that `config.WEB_DIST == <repo>/web/dist` and `config.BACKEND.name == "backend"`.
6. Update every **string** monkeypatch target in the tests (`"troubadour.engine.X"`, `"troubadour.asr.transcribe"`…) to the module where the symbol is now *used*. A patch on a re-export does nothing; tests may pass for the wrong reason. Grep `monkeypatch.setattr("troubadour.` and fix each one.
7. `tests/test_layers.py`: run import-linter in-process, for example `subprocess.run(["lint-imports", "--config", <root pyproject>])` and assert exit 0. Configure it in the root pyproject:
   ```toml
   [tool.importlinter]
   root_packages = ["troubadour.core", "troubadour.sound", "troubadour.lore", "troubadour.cloud", "troubadour.engine", "troubadour.server"]
   [[tool.importlinter.contracts]]
   name = "Layers"
   type = "layers"
   layers = ["troubadour.server", "troubadour.engine", "troubadour.cloud", "troubadour.lore | troubadour.sound", "troubadour.core"]
   ```
   If your import-linter version rejects `|` (independent siblings), use two contracts: a layers contract without sound, plus an `independence` contract for `troubadour.lore` and `troubadour.sound` and a `forbidden` contract stopping `troubadour.sound` from importing cloud, engine and server.
8. Ruff config stays at the root. W1 makes the root scripts path-agnostic (`ruff check .` from `backend/`), so nothing to change there; run `uv run ruff check .` yourself.
9. Delete `backend/src/` once it's empty. Update `backend/README.md` only if it names paths.
10. A short `AGENTS.md` in each package (`backend/packages/<pkg>/AGENTS.md`, at most 30 lines: what it is, what it may import, its invariants copied from `backend/AGENTS.md`, its test files), each with a `CLAUDE.md` symlink to it.

## Edge cases
- `writeup.EXAMPLE` and `dnd_terms` read files next to their module: check that they resolve (tests cover both).
- `sim.py` and the spike scripts import the engine: update them.
- `uv_build` namespace support: if `uv sync` can't build a member with a dotted `module-name`, switch that member to hatchling (`[tool.hatch.build.targets.wheel] packages = ["src/troubadour"]`) and report it.

## Acceptance
- `cd backend && uv sync --all-groups && uv run pytest` is all green, with the same test count as before plus your new tests (record both numbers in your report).
- `uv run ruff check . && uv run ruff format --check .` from `backend/`.
- `uv run lint-imports` passes. Add a deliberate `from troubadour.server import app` to a lore module, check it fails, then remove it.
- `scripts/scratch.sh 8770`: `curl -s 127.0.0.1:8770/api/state | head -c 200` returns JSON.
- `git grep -n "from \.\.\|troubadour\.\(config\|asr\|campaign\|memory\|server\)\b" backend` finds no old-style paths.
