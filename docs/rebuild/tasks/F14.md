## Build
- Rail (320px): `SearchInput` ("Names, aliases, heard as…"), type `PillGroup` (All, NPCs, Places, Items, Factions, PCs, plus a "Needs review N" warning chip), then the list (`NavItem`: name; sub = an alias or "suggested from S12"; a `TypeBadge`; items in legendary; a warning dot when it needs review). `/codex` without an entry selects the first.
- Main:
  - Header: serif 32px name + `TypeBadge` (accent); "Look for more facts" (starts `useSeekFacts`, shows `JobStatus`) and "Edit" (opens F15's `EditEntryDialog`).
  - Description (`FactText`); "Also called" aliases; "Heard as" chips: confirmed plain, suggested dashed with ✓/✕ wired to F15's `useHeardAsActions(entity)`.
  - **Appearances**: "mentions per session", page-local `AppearancesChart` (a bar per session S1…S12 from `appearances`; zero = a baseline tick).
  - **Facts** card: count, "Things still true next session", `FactsTable showAbout={false}`, with an add row (`addSlot`: "Add a fact, e.g. Owes Pip 20 gold" → serial write).
- Right rail (300px): "CONNECTED" (`connectedEntries`: name in its type colour + reason), then the note path (mono) and "Open in Obsidian", or the explanatory text when Obsidian doesn't know the vault.
- A suggested entry shows a banner "Suggested from S12. Keep it?" with Keep / Delete (F15's actions).
- **Create F15's stubs** in `edit/`: `EditEntryDialog.tsx` (`{ entity, open, onOpenChange }`, renders nothing), `actions.ts` exporting `useHeardAsActions(entity)` and `useSuggestedEntryActions(entity)` as no-op hooks with the final signatures: `{ accept(heard), reject(heard) }` and `{ keep(), remove() }`.
