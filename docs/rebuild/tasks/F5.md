## Build (`LiveTranscript.tsx` + private components)
- `TranscriptList mode="live"` over `toViewLines(messages, voices, players)`, with `highlightId` from `highlightT` (the line containing that time; cleared after 2.5 s), the footer "● Alex is speaking…" from `useSpeaking`, and speaker click → `LineSpeakerPicker` popover (port: reassign one line with `assignMessage`).
- Scene breadcrumb: **hidden** (deferred).
- **Ask bar** (44px, `border-line-strong`, accent on focus), placeholder "Ask a question (end with ?) or type a note to pin at the current time", a page-local `Kbd` "Enter" hint. Enter submits:
  - text ending in "?" → `ask(question, t = session time)`. An inline panel above the bar shows `AskAnswer compact` for that answer (searching → thinking → done), with a close button; Esc closes it. A source in the current session highlights its line; others use `TimestampLink`.
  - anything else → `addPin(t, text)`, clear the input, `notify("Pinned at 1:42:05")`, call `onPinned()`.
- Answers are never saved as facts.

## Tests
A question calls ask with `t`; a note calls `addPin`, toasts and calls `onPinned`; Esc closes the answer; a current-session source highlights its line; port the `ChatFeed` and `LineSpeakerPicker` tests.
