# S11 · CampaignSwitcher (switch, new, rename)

**Deps:** S1 · **Size:** S · **Owns:** `web/app/src/shell/CampaignSwitcher.tsx` (+ test)

## Read first
- Design: `Troubadour Nav.dc.html` (32px button on `bg-surface`, a class-coloured square, campaign name, chevrons-up-down).
- Old: `web/legacy/src/components/CampaignSwitcher.tsx` + test (switching rules, validation).

## Build
A `DropdownMenu` triggered by the button. Items: every campaign (check on the open one; select opens it via `openCampaign`), a separator, "New campaign…" (navigates to `/welcome/campaign?new=1`), "Rename…" (`Dialog` with a validated name input, `renameCampaign`). Switching is disabled while a session runs or campaign jobs are busy, with a tooltip saying why; a server 400 shows the detail with `notify`. The square uses the GM's class colour.

## Tests
Port the old tests; switching while running is disabled; rename validates empty and over-long names.

## Acceptance
`pnpm -C web/app test typecheck` and `pnpm -C web lint` pass.
