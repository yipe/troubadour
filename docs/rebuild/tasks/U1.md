## Build
1. `src/theme.css`: `@import "tailwindcss"; @import "@yipe/tokens/tokens.css"; @source "./";` (Tailwind v4 only scans files under the app's root by default. Without `@source`, the classes used in this package are silently missing from the build. That's the most likely "it works in tests but looks unstyled" bug.) Then
   `@theme inline { … }` with every key in the *Tailwind mapping* table, the font families, the text scale
   (`--text-*: initial;` first, then `--text-11` … `--text-34`, with `--text-14--line-height: 1.45`), the radii
   (`--radius-badge` 4px, `-control` 6px, `-card` 8px, `-dialog` 12px) and `--shadow-popover`. Base layer:
   `html { color-scheme: dark }`, body `bg-canvas text-ink font-sans text-14`, `::placeholder` in `ink-subtle`,
   links `text-accent hover:text-ink`, focus-visible ring `accent-strong`. Keyframes `flash` (2.5 s line
   highlight) and `speak-pulse`.
2. `src/lib/cn.ts`: `cn(...inputs)` = `twMerge(clsx(inputs))`, with tailwind-merge told about the custom text
   sizes (`extendTailwindMerge({ extend: { classGroups: { "font-size": [{ text: ["11","12",…,"34"] }] } } })`).
   Without that, `text-14 text-ink` would drop a class.
3. Components in `src/components/` (one file each, cva for variants, `forwardRef` not needed in React 19):
   - `button.tsx`: `Button` (variants and sizes from the catalogue; `asChild` via base-ui `render` prop if the old button had it). Primary is `bg-accent-strong text-ink-on-accent`; secondary is `bg-surface border-line`; warning is `bg-warning text-black` ("Start review"); danger is `bg-danger-soft text-danger`.
   - `badge.tsx`: `Badge` (tones; 12px, 600, `px-[7px] py-px`, `rounded-badge`).
   - `status-dot.tsx`: `StatusDot` (7px; `pulse` uses `speak-pulse`).
   - `card.tsx`: `Card`, `CardHeader` (`title` in `font-serif`, `meta`, `action`), `CardBody`.
   - `page-heading.tsx`: `PageHeading` (`eyebrow` 13px accent serif link-style, `title` serif 30–34px bold, `subtitle` muted, `actions`).
   - `section-label.tsx`: `SectionLabel`.
   - `avatar.tsx`: `Avatar` (`initials`, `color` CSS value via `--avatar`, 22% tint background via `color-mix(in oklch, var(--avatar) 22%, transparent)`, 1.5px inset ring, sizes 24/30/36/44, optional `src`).
   - `spinner.tsx`: `Spinner`.
4. `src/gallery/index.tsx`: `export function Gallery()` renders the `Section` named export of every `src/gallery/sections/*.tsx` file (each section file exports `title` and `Section`; no default exports), found with `import.meta.glob("./sections/*.tsx", { eager: true })`, in file-name order, each under a heading. Add `sections/base.tsx` showing every variant of this task's components.
5. Tests (`src/components/base.test.tsx`): Button renders each variant and passes `onClick`; Avatar exposes the colour as `--avatar`; `cn("text-14", "text-ink")` keeps both classes.
