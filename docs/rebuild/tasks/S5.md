## Build
- `suggestion/SuggestionCard.tsx`: `{ kind: "fact"|"update"|"entry"|"spelling"|"pin", about?, entryType?, text, old?, confidence?, who?: {name, color}, t?, sessionId?, status: "open"|"done", tone?: "default"|"accepted", actions: ReactNode, onJump? }`.
  Header: kind label ("Fact" `text-accent`, "Updates a fact" `text-info` with an info-tinted border while open, "New entry" `text-very-rare`, "Spelling" `text-info`, "Note" for pins) + "→ <about>" + `ConfidenceBadge` (or a "Spelling" info badge) on the right. Body: `old` struck through in `ink-subtle`, then `text`. Footer: who dot + name + `TimestampLink`, then `actions`. `status: "done"` dims it to 0.75 opacity; `tone: "accepted"` gives a success border.
- `ask/AskAnswer.tsx`: `{ answer: CampaignAnswer, onSource(source), compact? }`. States: queued/searching ("Searching 13 transcripts and 214 notes on this Mac…" when stats exist, else "Searching…"), thinking, error (message + retry slot), done. Done: the answer in serif (24px full, 18px compact). Citation tokens like `[S1]` become superscript numbers in source order; quoted phrases that match a source excerpt get `bg-accent-soft`. Source rows: number, avatar (for transcript sources), "who · Session N · time", the quote, and "Play line" (`TimestampLink`) or "Open note" (`EntityLink` / path). Footer: "Answered on this Mac in {s} s from {transcripts} transcripts and {notes} notes" when `stats` exists. `found === false`: "The notes don't say." styling.
- `facts-table/FactsTable.tsx`: `{ rows: FactRow[], showAbout = true, emptyText, addSlot?: ReactNode }` where `FactRow = { fact: Fact, about?: {name, type} }`. Columns as in 1k: Fact (with `FactText`), About (name + type below; hidden in the codex), Said by (avatar + name), Source (`▷ S12 · 1:41:55` → `TimestampLink`), How sure (`ConfidenceBadge`). A fact with history shows "Changed once · history open" under its text; clicking it toggles a `sunken` block listing versions, current first, older ones struck through with who and session/time. Zebra rows; virtualize only if `rows.length > 300` (use `TableVirtuoso`).

## Tests

- `AskAnswer` maps `[S2]` to the right number and source row; "Play line" plays the source's time; the stats footer appears only with stats.
- `FactsTable` expands and collapses history; `showAbout={false}` drops the column.
