## Build
1. `src/index.css`: `@import "@troubadour/ui/theme.css"; @source "./";`. `main.tsx`: import `./index.css`; create one socket (`createSocket()`), one QueryClient (`makeQueryClient()`); `wireLive(socket)`, `bridgeSocket(socket, client)`, `socket.connect()`; render `<App/>` in an `ErrorBoundary`.
2. `App.tsx`: `QueryClientProvider`, base-ui `Tooltip` provider if needed, `Toaster`, `SessionAudioProvider` (create `components/audio/SessionAudioProvider.tsx` as a passthrough `({children}) => children`; S3 fills it), `RouterProvider`.
3. `routes.tsx`: every route in the *Routes* table, with lazy imports (`lazy: () => import("./pages/<page>")`). Two layouts:
   - `shell/AppLayout.tsx`: TopNav + server error banner + `<Outlet/>`, filling the viewport (`h-dvh flex flex-col`; pages fill the rest).
   - `shell/BareLayout.tsx` (wizard): just the outlet.
   Old-URL redirects (`/setup`, `/session`, `/history[/:id]`, `/campaign[/:entry]`). `/dev/ui` renders `Gallery` only when `import.meta.env.DEV`. A catch-all 404 page with a link home.
4. Stub pages: `pages/<page>/index.tsx` for `home, welcome, ready, live, review, sessions, transcript, timeline, codex, facts, recap, ask, settings`. Each exports `Component` (React Router's lazy-route convention; no default exports anywhere) rendering `<PageHeading title="<Page name>" subtitle="Coming in task F<n>"/>`. Inside `pages/live/`, also create the empty region components F4 expects: `transcript/LiveTranscript.tsx`, `notebook/Notebook.tsx`, `end/EndSessionDialog.tsx`, each a stub with the props documented in F4.
5. Startup redirects (in `pages/home` loader or a `RootGate` component in `shell/`): until the live store is `loaded`, show "Waiting for the Troubadour server…" centred. Then at `/`: if no seated players **and** no saved sessions → `/welcome/campaign`; if a session is running or paused → `/sessions/live` (first load only, so the user can still go Home later). `/sessions/live` with no session → `/sessions`.
6. `shell/TopNav.tsx` (56px, `border-b border-line`), from the nav design:
   - Left: feather icon (`text-accent`) + "Troubadour" (Georgia 18px bold) linking home, then `<CampaignSwitcher/>`.
   - Tabs (`UnderlineTabs size="nav"` with router links): Home · Sessions · Timeline · Codex · Facts · Ask. Sessions is active on `/sessions/*` and has a red dot while a session runs.
   - Right: `<RecordingPill/>` (only while running or paused: `bg-danger-soft text-danger`, "RECORDING", 12px bold, 0.06em tracking, tabular elapsed `h:mm:ss` from `useSessionTime`; "PAUSED" in warning; links to `/sessions/live`), `<CloudChip/>`, `<AiStatus/>` (lock icon + "On this Mac" when the LLM provider is local, otherwise the provider label; a dot plus "AI ready" when `session.asr.state === "ready" && session.llm.ok`, "AI loading" (warning) or "AI off" (danger); links to `/settings/models`), `<AccountMenu/>`.
7. Stubs for `shell/CampaignSwitcher.tsx`, `shell/CloudChip.tsx` and `shell/AccountMenu.tsx` that render the right-size placeholder (the campaign name, a cloud icon, initials). S11, S12 and S13 replace them; keep their file names and default props.
8. `shell/ErrorBanner.tsx`: `session.error` as a full-width danger strip under the nav.
9. `paths.ts` (in `src/`, owned with `routes.tsx`): typed builders for every route: `paths.home()`, `paths.session(id)`, `paths.review(id)`, `paths.transcript(id, t?)`, `paths.recap(id)`, `paths.codex(entry?)`, `paths.facts(filters?)`, `paths.settings(section)`, `paths.welcome(step)`. Every link in the app uses them, never a string literal, so changing a URL is one edit. `routes.tsx` builds its patterns from the same constants.
10. `test/setup.ts` (jest-dom, cleanup, `scrollIntoView` and `ResizeObserver` stubs, toast clearing) and `test/render.tsx`: `renderWithProviders(ui, { route = "/", live?: Partial<LiveState>, queryData?: [key, data][] })` with a fresh QueryClient, a `MemoryRouter` (or `createMemoryRouter`) and a seeded live store.

## Tests
- Routing: each old URL redirects to its new one; `/dev/ui` doesn't exist in production mode (mock `import.meta.env.DEV`).
- Startup: loaded with no players and no sessions → `/welcome/campaign`; a running session on first load → `/sessions/live`.
- TopNav: Sessions is active on `/sessions/12/review`; the recording pill appears only while running; AiStatus says "AI ready" only when both models are up.
