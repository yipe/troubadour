# F6 · Live: Tonight's notebook

**Deps:** F4, S5, C3 · **Size:** M · **Owns:** `web/app/src/pages/live/notebook/`

## Read first
- `docs/design/troubadour-redesign/Live Prototype.dc.html` (`CARDS`, `NAMES`, `mk()`, tabs, empty texts, toast with Undo), README §1f right.

## Build (`Notebook.tsx`, props from F4)
- Header: notebook icon + serif "Tonight's notebook"; right: "kept facts go to the review" or "3 kept for review"; a spinner while `updating`.
- `UnderlineTabs size="panel"`: Facts (fact and update items), Names (entry and spelling items), Pins, each with the count of visible items (open + kept).
- Cards = `SuggestionCard`s, newest first, dismissed ones hidden:
  - fact → "Keep" / "Dismiss"; update → "Keep update" / "Dismiss"; entry → "Add to codex" / "Dismiss"; spelling → "OK" / "Dismiss"; kept → "✓ Kept" (dimmed); pins → read-only "Note" cards ("Pinned by you").
  - Dismiss → `notify("Dismissed", { undo: () => setStatus(id, "open") })`.
  - The timestamp → `onJump(t)`.
- Empty texts: Pins "Type a note in the bar below and press Enter to pin it to the current moment."; others "Nothing new yet. Facts show up a few minutes after they're said."
- Nothing is written to the vault here; the review handles kept items (C8).

## Tests
Tabs and counts; Keep marks kept; Dismiss + Undo restores; the timestamp calls `onJump`; a `notebook.updated` event re-renders.
