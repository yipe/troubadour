# S8 · PlayersTable + TrainDialog

**Deps:** S3, C1 · **Size:** M · **Owns:** `web/app/src/components/players/`

## Read first
- Design: `Screen Setup.dc.html` (the table: columns `52px 1.1fr 1.3fr 1fr 80px 220px`, the "already trained" banner, the dashed "+ Add player" row), `screenshots/1a-setup-wizard.png`.
- Old: `web/legacy/src/components/setup/{PlayerCard,LibraryList,TrainDialog,SetupView}.tsx`, `LibraryList.test.tsx`.
- `@troubadour/api/players` (C1: `dnd_class`, `color`), `@yipe/tokens/classes`.

## Build
- `PlayersTable`: `{ mode: "wizard"|"settings" }`. Reads the seated players and library from the live store.
  - Row: avatar (click to upload an image, as `fileToAvatar` did), player name input, character input (placeholder "Game master" for the GM), class `NativeSelect` with a colour dot, listing `useClasses()`: built-ins, then custom classes, then "—" and "Add a class…". "Add a class…" opens a small `Dialog` (name + `ColorSwatchPicker`) that posts to `/api/classes` and selects the new class, role ("GM" in paladin colour, else "Player"; a row menu toggles GM), and voice: "Trained" (success, circle-check) or "Learns in play" (circle-dashed, `ink-subtle`) with an outline **Retrain**/**Train** button (audio-waveform icon).
  - Row menu ("…"): Custom colour (`ColorSwatchPicker` with "Use class colour"), Make GM / Not GM, Bench (removes from this campaign, keeps voice), Remove for good (`ConfirmDialog`).
  - Edits save on blur or Enter via `updatePlayer` (PATCH). An optimistic local value with rollback and `notify` on error.
  - The dashed "+ Add player" row adds a player named "New player" and focuses its name input.
  - Above the table: when the library has players with trained voices not seated here, an info banner "N players from <campaign> already have trained voices." + "Add <names>" (`seatPlayer` for each).
  - Both modes render the same table. Voice clones are not here; they live in F20.
- `TrainDialog`: port (20 s countdown, level, progress, cancel, error), restyled with `Dialog` and `Progress`.

## Tests
- Changing the class sends `PATCH {dnd_class}`; "Add a class…" posts `{label, color}` and then patches the player with the new id; picking "Use class colour" sends `{color: null}`.
- The library banner seats every listed player.
- Train opens the dialog; Cancel calls `cancelTraining`.
