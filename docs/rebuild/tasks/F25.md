**Deps:** S8, F20 · **Size:** S · **Owns:** see `dag.toml`

Owner request (2026-10-30): make a player's Role a dropdown in Players & voices, instead of the row menu's
"Make GM" / "Not GM" items.

## Read first
- `web/app/src/components/players/PlayerRow.tsx` (the Role cell ~line 199 shows "GM"/"Player"; the row menu has the Make GM / Not GM item ~line 226), `PlayersTable.tsx`, `PlayersTable.test.tsx`.
- `@troubadour/ui/native-select` (or the select the class column already uses) for the control.

## Steps
1. Replace the Role text with a compact select: "Player" / "GM". Changing it saves `{ is_gm }` through the same optimistic `save` path the row already uses (rollback + toast on error).
2. Remove the "Make GM" / "Not GM" item from the row menu.
3. Keep the GM's paladin colour on the select's text when GM. Accessible name: "Role for <name>".
4. Same control in every mode the table is used in (settings, wizard, ready check).

## Tests
Selecting GM sends `PATCH … {is_gm: true}` and selecting Player sends `false`; the row menu no longer has a GM item; a failed save rolls the select back.
