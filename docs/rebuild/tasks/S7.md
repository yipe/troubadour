# S7 · MicCard: device, level meter, checklist, mic test

**Deps:** S1, S2 · **Size:** M · **Owns:** `web/app/src/components/mic/`

## Read first
- Design: `Screen Lobby.dc.html` (the Microphone card: device select, 48-bar meter, labels quiet/"Say a few words from each seat"/clipping, checklist with values), `screenshots/1c-ready-check.png`.
- Old: `web/legacy/src/components/audio/{MicTest,MicDetails,LevelMeter,QualityRows,LiveQualityBox}.tsx`, `lib/audio.ts`, `MicSetup.test.tsx`, `LevelMeter.test.tsx`.
- `@troubadour/api/live` audio (`subscribeLevel`, quality, `mic.test`) and `@troubadour/api/audio` (mics, `startMicTest`/`stopMicTest`).

## Build
- `MicCard`: `{ mode: "ready"|"wizard"|"settings", device, onDeviceChange, sources?: SourceList }`. Header: `SectionLabel`-style title "Microphone" with a status circle (success when quality is good, warning otherwise, neutral before a test), and the device `NativeSelect` on the right ("Jabra Speak 710 (default)"). In `ready` mode only, the select also lists "Replay a file…" and "Replay a saved session…" groups from `sources` (the old StartPanel source kinds; dev aids, kept).
- `LevelMeter48`: 48 bars, rAF-throttled from `subscribeLevel`. Height follows recent level per bar; colour by zone (quiet `ink-subtle`, good `success`, hot `warning`, clip `danger`). Labels under it.
- `MicChecklist`: rows from the mic's `MicCheck[]` (around → "Omnidirectional pickup" with its pattern value, etc.) and the quality grades ("Level" with avg dB, "Background noise" with low/ok/high). Each row has a check, warning or neutral icon. No "Heard all seats" row (deferred).
- Test control: when no session is running, a "Test" button starts the mic test (`startMicTest`) and "Stop" ends it. The mic test is **user-initiated only**; never start it on mount.

## Tests
Port `MicSetup.test.tsx` and `LevelMeter.test.tsx`. Mounting never calls `startMicTest`; clicking Test does; in `ready` mode the replay options appear and selecting one calls `onDeviceChange` with a file source.
