## Build
`GET /api/storage` → `{root: str, recordings: int, voices: int, notes: int, other: int}` (bytes). Recordings are
`sessions/*/audio.wav` (and any `*.wav` under `sessions/`); voices are `voices/` plus `clones/`; notes are the open
campaign's vault folder (wherever it lives, even outside `DATA_DIR`); other is everything else under `DATA_DIR`.
`root` is shown with `~` for the home directory. It walks the tree off the event loop (`run_in_threadpool`) and
caches the result for 60 s. It skips symlinks and follows no links out of the tree.

## Web
`@troubadour/api/storage`: type, endpoint, `useStorage()`.

## Contract rule
Every endpoint you add or change declares a pydantic `response_model` (payload shapes as classes in the router, or in `server/models.py` when two routers share one). In `@troubadour/api`, its types are `Schemas["<Model>"]` from `../generated` (the B6 recipe), not hand copies. WebSocket payloads reuse the same models. Run `pnpm -C web/packages/api gen` after changing a model.

## Tests (`test_storage.py`)
Bytes per bucket on a tmp data dir; a vault outside the data dir counts as notes; the cache.
