## Build (pure functions unless noted; each file has a `.test.ts`)
- `format.ts`: **one** set of formatters, all with an explicit `"en-US"` locale (`Intl.DateTimeFormat("en-US", …)`; the old code passed `undefined`, which makes output depend on the machine), replacing the three duplicates. `hms(s)` "1:38:02" (hours always shown when ≥ 1 h, else "38:02"), `hm(s)` "1:38", `duration(s)` "3 h 12 m" / "45 m" / "40 s", `durationShort(s)` "3:12" (h:mm), `dateShort(epoch)` "Oct 22", `dateLong(epoch)` "Thursday, October 22", `timeRange(start, end)` "7:04 – 10:16 pm", `ago(epoch, now)` "4 min ago" / "just now" / "Oct 22", `bytes(n)` "3.1 GB".
- `players.ts`: `playerColor(p, classes: DndClass[])` per the shared rule (an override hex; else the class colour: `classColorVar(id)` from `@yipe/tokens/classes` for a built-in, the class's own `color` for a custom one; else paladin for the GM; else `var(--color-fg-subtle)`). A `dnd_class` id that isn't in `classes` (deleted) falls through to the next rule. Until C1 merges, `DndClass` doesn't exist: S2 must not depend on C1, so type the parameter locally as `{ id: string; color: string | null; builtin: boolean }[]`; `initials(name)`; `speakerFor(...)` and `speakerKey(...)` (port of `speaker.ts`, one implementation for live and saved records).
- `talk.ts`: port `talkTime.ts` (`recordTalkTime`, `sharePct`, `talkDuration`). Add `talkSegments(talk: Record<string, number>, players)` → `{value, color, label}[]` ordered like the players list, unnamed voices grouped as "Others", and `topPlayer(talk, players)` (excluding the GM) → `{player, pct, seconds} | null`.
- `confidence.ts`: `CONFIDENCE = { gm: {label: "GM stated", tone: "success"}, theory: {label: "Party theory", tone: "warning"}, once: {label: "Heard once", tone: "neutral"} }`.
- `entities.ts`: port `campaign.ts` (`TYPE_LABEL`, `TYPE_PLURAL`, `ENTITY_TYPES`, `needsReview`, `matchesSearch`, `findEntity`, `splitWikiLinks`, `latestJob`, `jobActive`, `jobCount`). Add `entityTone(type)` (items → `legendary`; others neutral) and `connectedEntries(entity, campaign)` → `{name, reason}[]`: entries linked from this entry's description or facts, plus entries whose facts link here; `reason` is the linking fact's text, cut at 60 chars; no duplicates; the entry itself excluded.
- `sessions.ts`: `sessionNumbers(sessions)` → `Map<id, n>` (oldest first, merged-away sessions skipped) and `nextSessionNumber(sessions)`; `sessionStatus(s, writtenUp)` → `"needs-review" | "reviewed" | "not-written-up"`.
- `fixes.ts`: port `splitFixes` (UTF-16 offsets).
- `record.ts`: port `loadRecord` and its view types.
- `signIn.ts`: `openSignIn(getUrl: () => Promise<string>)`. Opens `about:blank` synchronously (pop-up blockers allow only that), sets `opener = null`, then sets the URL after the await, and closes the tab on error. This replaces the two copies in `cloudStore` and `ModelsDialog`.

## Tests
`hms` and `sessionNumbers` are tested against `shared/test-vectors/{hms,session-numbers}.json` (import the JSON; loop over the cases). Port the old tests and add: `hms(59)` "0:59"; `hms(3600)` "1:00:00"; `sessionNumbers` skips merged sessions; `playerColor` override beats class (built-in and custom) beats GM beats fallback, and an unknown class id falls through; `connectedEntries` finds links both ways without the entry itself; `talkSegments` with an unknown voice puts it under "Others".
