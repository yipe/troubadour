# W1 · pnpm workspace (app, ui, api, tokens), legacy app parked, all deps pinned

**Deps:** P0 · **Size:** M · **Owns:** `web/`, root `package.json`, `scripts/dev.sh`, `.github/workflows/ci.yml`

## Read first
- `architecture.md` → *Layout*, *Web packages*, *Tech choices*.
- `web/AGENTS.md`, `web/package.json`, `web/vite.config.ts`, `web/vitest.config.ts`, `web/tsconfig*.json`, `web/.oxlintrc.json`, `web/.prettierrc*`.

## Goal
`web/` becomes a pnpm workspace with four packages, all built and checked by `yarn check`. The old app moves
to `web/legacy/`, untouched and excluded from every script. Every dependency the plan needs is installed now,
so later tasks never edit a lockfile.

## Steps
1. `git mv` the old app (`src`, `public`, `index.html`, `components.json`, its `package.json`, tsconfigs, vite/vitest configs) into `web/legacy/`. Don't list it in the workspace. Add `web/legacy/README.md`: "Old UI, kept for reference until X2 deletes it. Not built or tested."
2. Workspace root `web/package.json` (private), `web/pnpm-workspace.yaml` (`packages: [app, packages/*]`), `web/tsconfig.base.json` (`strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `moduleResolution: bundler`, `jsx: react-jsx`, `verbatimModuleSyntax`), shared `web/.oxlintrc.json` and `web/.prettierrc` (moved from the old app, unchanged rules).
3. Packages, each with `package.json`, `tsconfig.json`, `vitest.config.ts` (jsdom where React is involved) and `src/`:
   - `web/packages/tokens` → `@yipe/tokens`. Exports `"./tokens.css": "./tokens.css"` and `"./*": "./src/*.ts"`. Deps: none. Placeholder `tokens.css` with one comment line; U0 fills it.
   - `web/packages/ui` → `@troubadour/ui`. Exports `"./theme.css": "./src/theme.css"`, `"./gallery": "./src/gallery/index.tsx"` and `"./*": "./src/components/*.tsx"`. Deps: `@yipe/tokens` as `workspace:*` (so it can never resolve to the npm registry by accident), `@base-ui/react`, `class-variance-authority`, `clsx`, `tailwind-merge`, `lucide-react`, `sonner`, `cmdk`; peers `react`, `react-dom`.
   - `web/packages/api` → `@troubadour/api`. Exports `"./*": "./src/*/index.ts"`. Deps: `@tanstack/react-query`, `zustand`; peers `react`. Dev: `@testing-library/react`.
   - `web/app` → `@troubadour/app`. Deps: the three workspace packages, `react`, `react-dom`, `react-router`, `@tanstack/react-query`, `react-virtuoso`, `lucide-react`, `html-to-image`, `zustand`. Dev: `vite`, `@vitejs/plugin-react`, `tailwindcss`, `@tailwindcss/vite`, `playwright`.
   - Shared dev deps at the workspace root: `typescript`, `vitest`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`, `oxlint`, `prettier`, `prettier-plugin-tailwindcss`, `@types/react`, `@types/react-dom`, `@types/node`.
   - Use the versions the old app pins for anything it already had (React 19.2, Vite 8, TS 6, Tailwind 4.3, vitest 5, zustand 5, react-virtuoso 4.18, lucide, @base-ui/react 1.8, sonner 2, cmdk 1.1). New packages: latest stable majors (react-router 7, @tanstack/react-query 5, html-to-image 1, playwright 1). Then run `pnpm exec playwright install chromium`.
4. `web/app`: `index.html` with `<html lang="en" data-theme="dark">`, `src/main.tsx` rendering "Troubadour" (S1 replaces it), and `vite.config.ts` with the react and tailwind plugins, alias `@/` → `src/`, `build.outDir: "../dist"`, `emptyOutDir: true`, and the dev proxy `/api` and `/ws` → `127.0.0.1:${TROUBADOUR_PORT ?? 8765}` (ws: true). `/auth` and `/api/llm/openrouter/callback` are proxied too.
5. Workspace scripts (`web/package.json`): `dev` (app), `build` (app), `test` (`TZ=UTC vitest run` with the root projects config from step 8; each package also keeps its own `test` script for scoped runs), `typecheck` (`pnpm -r typecheck`), `lint` (`oxlint` over `app/src` and `packages/*/src`), `format`, `format:check`. In `web/app/package.json` add `shot` and `smoke` (`node scripts/shot.ts` and `node scripts/smoke.ts`; Node 24 runs TypeScript directly), which W2 implements.
6. Root `package.json`: keep yarn and every script name. Point the web scripts at the workspace (`cd web && pnpm …`). Make the Python scripts path-agnostic, so they work before and after B1 moves the code: `ruff check .`, `ruff format .` and `ruff format --check .` run from `backend/` (ruff skips `.venv`). `scripts/dev.sh`: unchanged except for the `yarn dev:web` target if needed.
7. CI (`.github/workflows/ci.yml`): cache key on `web/pnpm-lock.yaml`. Add a `pnpm exec playwright install chromium` step only if a check needs it (none does yet: smoke is manual).
8. **One test run for the workspace:** a root `web/vitest.config.ts` with `test.projects: ["app", "packages/*"]`, so `pnpm test` is one vitest process. Set `TZ=UTC` in the `test` script (`TZ=UTC vitest run`): dates in tests must not depend on the machine. Add a `browser` project for the app (Vitest browser mode, Playwright provider, Chromium headless with `--mute-audio`, 1440×900) that runs `*.browser.test.tsx` files. Add `test/shot.ts`, used as `await shot("live-notebook-update")`: when `SHOT=1`, it saves a screenshot to `/tmp/troubadour-shots/<name>.png`; otherwise it does nothing.
9. **Boundary lint rules** in `web/.oxlintrc.json` (`overrides` by file glob; see `conventions.md` §1):
   - `packages/ui/**`: `no-restricted-imports` for `@troubadour/api` and `@troubadour/api/*`.
   - `app/src/**` and `packages/ui/**`: `no-restricted-globals` for `fetch` ("Use a query hook from @troubadour/api").
   - `app/src/pages/**`: `no-restricted-imports` pattern `@/pages/*` ("Promote shared code to app/src/components").
   - Add `import/no-default-export` (or oxlint's equivalent) everywhere except `*.config.ts`.
   Prove each rule fires with a throwaway violation, then remove it.
10. **Generated API types (B6 fills this in):** `web/packages/api/scripts/gen.ts` as a stub that writes `src/generated/index.ts` containing `export type Schemas = Record<string, never>`; scripts `"gen": "node scripts/gen.ts"` and `"pretypecheck": "pnpm gen"` in `@troubadour/api`, and `"pretypecheck": "pnpm -C ../packages/api gen"` in `@troubadour/app`; `web/packages/api/src/generated/` in `.gitignore`. Add `openapi-typescript` to the api package's dev deps now.
11. **Package guides:** an `AGENTS.md` in each of `web/`, `web/app`, `web/packages/{tokens,ui,api}` (at most 40 lines: purpose, commands, rules, gotchas; copy from `conventions.md` and `architecture.md`), each with a `CLAUDE.md` symlink (`ln -s AGENTS.md CLAUDE.md`), the repo's convention. Move the old `web/AGENTS.md` content that still applies; the rest goes with the legacy app.

## Edge cases
- The backend serves `web/dist`: the app build must land there (`outDir: "../dist"`).
- `CI=true` in the shell: the first install needs `pnpm install --no-frozen-lockfile`, once.

## Acceptance
- `cd web && pnpm install && pnpm -r typecheck && pnpm test && pnpm lint && pnpm format:check && pnpm build` all pass (empty test suites pass with `--passWithNoTests`).
- `ls web/dist/index.html` exists after the build.
- `git grep -n "legacy" web/pnpm-workspace.yaml` finds nothing.
- Each boundary rule fails on a planted violation (list the four commands and outputs in your report).
- `yarn lint:backend` passes both before and after B1's merge (it doesn't name a path).
