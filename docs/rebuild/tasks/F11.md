**Deps:** S4 · **Size:** M · **Owns:** `web/app/src/pages/transcript/`

## Read first
- Old: `web/legacy/src/components/history/SessionViewer.tsx` + test, `lib/record.ts`. No design: `RailLayout`, `PageHeading`, S4's transcript styling.

## Build
`/sessions/:id/transcript?t=<seconds>`: rail (300px) with the session title and date, speakers with talk share, play/pause for the session audio, and links back to the session and the review. Main: `TranscriptList mode="static"` of the record; `?t=` scrolls to and highlights that line; timestamps play from that line (no autoplay). A search box filters by text, highlighting matches, without remounting the list.
