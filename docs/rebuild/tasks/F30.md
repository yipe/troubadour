# F30 · Manage sessions: delete, merge from the list, tidy very short ones

**Deps:** F9, F10, F24 · **Priority:** high (data safety) · **Size:** M · **Owns:** see `dag.toml`

Owner request (2026-10-30): there's no way to delete a session, and merging is hidden at the bottom of the
detail page. A 3-second session should be easy to get rid of or fold into its neighbour.

## First, and most important: merging must never lose data (owner hit this on real data)
A merge in the real app returned 500 after it had already deleted the later session's folder. Today
`Engine.merge_sessions` (`engine/_sessions.py`) does `shutil.rmtree(drop_dir)`, deletes the kept session's
`transcript.orig.json` (Improve's restore point) and `quality.json`, and rewrites `meta.json` from the
transcript's `session` dict, which can drop fields that live only in `meta.json` (e.g. `campaign`, `title`,
`present_player_ids`, `reviewed_at`). With `campaign` gone the merged session falls out of the open
campaign's list, so the route's `next(...)` raises StopIteration: the 500.
Fix, with a test for each:
1. Build the merged meta from the kept session's `meta.json` overlaid with the merged values, and always set
   `campaign` to the open campaign. The route never raises a bare StopIteration (clear 404/409 if the kept
   session somehow isn't listed).
2. Nothing is deleted: the later folder moves to `sessions/.trash/<id>` (timestamp suffix if taken); the kept
   session's pre-merge `transcript.json`, `transcript.md`, `meta.json`, `quality.json` and
   `transcript.orig.json` move to `<kept>/.premerge/`, with `merge.json` recording the dropped id and the
   kept `audio.wav` byte size before concatenation.
3. `POST /api/sessions/{id}/unmerge` undoes the last merge: restores the `.premerge` files, truncates
   `audio.wav` back to its saved size, moves the dropped folder back from `.trash`. 409 if there's nothing to
   undo or the dropped id's slot is taken.
4. The merge confirm says it can be undone; after a merge, `notify("Sessions merged", { undo })` calls unmerge.
5. Tests use real WAV files in tmp dirs: merge then unmerge restores both folders byte-for-byte (audio
   included); a session whose transcript `session` lacks `campaign` stays in its campaign after a merge.

## Steps
1. Backend: `Engine.delete_session(sid)` moves `sessions/<sid>/` to `sessions/.trash/<sid>/` (suffix a timestamp if taken); refuses the live session (ValueError → 400) and unknown ids (404). Never deletes files. The vault's write-up page stays (it's the user's note). `Engine.undelete_session(sid)` moves it back if the slot is free. Both emit `library.updated`/whatever `list_sessions` consumers already listen to, and the sessions list no longer shows trashed ones. `.trash` is skipped everywhere sessions are scanned (list, Ask, timeline, numbering).
2. Routes: `DELETE /api/sessions/{sid}` → 204; `POST /api/sessions/{sid}/undelete` → `SavedSession`. Session ids pattern-checked. Add to `tests/test_routes.py`.
3. Web API: `deleteSession`, `undeleteSession`, hooks invalidating `keys.sessions()`.
4. Detail header: a "…" `DropdownMenu` beside Export with "Merge with…" (opens the existing MergeDialog) and "Delete…" (ConfirmDialog: "Moves the recording and transcript to the trash. The write-up note in your vault stays."). After delete: navigate to `/sessions`, `notify("Session deleted", { undo })`. Remove the footer merge link.
5. List: each row gets a hover/focus "…" menu (Merge with next/previous, Delete…). Rows under 60 s get a "Very short" badge. When any exist, a slim banner at the top of the list: "N sessions are under a minute." with "Review" (filters the list to them) and "Delete them…" (one confirm, then one undo toast for all).
6. Optional multi-select: checkboxes appear on hover / when one is checked; a bar shows "Merge selected" (enabled for 2+, merged oldest-first) and "Delete selected".

## Tests
- Python: delete moves the folder to `.trash` and hides it from the list, numbering and Ask; undelete restores; the live session can't be deleted; unknown id 404; traversal ids refused.
- Web: header menu deletes with confirm + undo; footer link gone; very-short badge and banner; bulk delete sends one DELETE per session; merge from the row menu opens the dialog preselected.
