# F12 · Timeline: the story so far (4a)

**Deps:** S3, C9 · **Size:** M · **Owns:** `web/app/src/pages/timeline/`

## Read first
- `docs/design/troubadour-redesign/screenshots/4a-timeline-vertical.png`, `docs/design/troubadour-redesign/Screen Timeline C.dc.html`, README §4a. (3b and 3c are alternatives.)

## Build
- Header: `PageHeading` "The story so far", subtitle "12 sessions · newest first · scrolls as the campaign grows", and a player colour legend on the right.
- Table (columns `200px 300px 280px 1fr 90px`), one 60px row per session, newest first, virtualized (`TableVirtuoso`) so it holds up past 50 sessions:
  1. Session: "S12" (serif bold) + date, then the title.
  2. **Where**: page-local `TravelLine`. Each distinct place gets a fixed horizontal lane (by first appearance in the campaign; at most 6 lanes, reusing the least recently used beyond that). A 3px `line-strong` vertical line runs through the rows, hopping horizontally at a row's bottom when the place changes. A 12px dot: `accent` where a new place starts (labelled with the place), `accent-strong` for the newest session, `line-strong` otherwise. One SVG per row, drawn from this row's lane and the next row's.
  3. **Who talked**: a 10px stacked `TalkShareBar` (no legend) + "Top player: Pip 17% · 3:12" (GM excluded).
  4. **New faces**: `Chip`s linking to the codex (items in legendary).
  5. **Facts learned**: an accent bar scaled to the campaign maximum + the count.
- The newest row is `bg-accent-soft`. Clicking a row opens `/sessions/:id`.

## Tests
The lane helper (page-local, unit-tested): stable lanes, a hop on a place change, a session without places continues the line; top player excludes the GM; rows link to sessions.
