# F24 · The table's name (party name), default "The table"

**Deps:** F1, F3, S11 · **Size:** M · **Owns:** see `dag.toml`

Owner request (2026-10-30): in a campaign's setup, the group can name the table (the party's name for
itself, e.g. "Magic Mushroom Mob"). Where the UI says "The table" today, it shows that name; without one it
stays "The table".

## Read first
- `backend/packages/engine/src/troubadour/engine/state.py` (`Campaign`, `to_json`), `_sessions.py` (state load, ~line 349), `_library.py` (`create_campaign`, `rename_campaign`).
- `backend/packages/server/src/troubadour/server/routers/players.py` (`CampaignIn`, `CampaignInfo`, `PATCH /api/campaigns/{cid}`).
- `web/packages/api/src/campaigns/` (types from `Schemas`, endpoints, hooks), `web/app/src/pages/welcome/CampaignStep.tsx`, `steps.ts`, `web/app/src/pages/home/TheTable.tsx`, `web/app/src/pages/ready/index.tsx`, `web/app/src/shell/CampaignSwitcher.tsx` (rename dialog).

## Steps
1. Backend: `Campaign.table_name: str = ""` (saved in `state.json`; an old state without it loads as ""). `to_json` adds `table_name`. `PATCH /api/campaigns/{cid}` accepts an optional `table_name` (stripped, ≤ 60 chars, may be empty to clear) alongside or instead of `name` (make `name` optional too; at least one must be given → else 422/400). `CampaignInfo` gains `table_name: str`. Emit `campaigns.updated` as rename does.
2. Web API: regenerate types (`COREPACK_ENABLE_STRICT=0 pnpm -C web/packages/api gen`), `CampaignInfo` stays `Schemas[...]`; the rename endpoint/hook takes `{ name?, table_name? }`.
3. A pure helper `tableName(campaign)` → `campaign.table_name.trim() || "The table"` in `web/app/src/lib/` (new file `table.ts`).
4. Welcome campaign step: an optional "Your table's name" field (placeholder "e.g. Magic Mushroom Mob", hint "What the party calls itself. Leave empty for “The table”."), saved with the campaign. The rail/step copy that says "The table" uses the helper.
5. Home's table card heading and the ready check's "who's here" heading use `tableName(...)` of the open campaign.
6. The campaign switcher's Rename dialog also edits the table name (second field).

## Tests
- Python: old `state.json` without `table_name` loads; PATCH sets, clears and caps it; `campaigns.updated` carries it.
- Web: `tableName` default and trim; Home heading shows the name and falls back to "The table"; the welcome step sends `table_name`; the rename dialog sends both fields.

## Acceptance
`yarn check` passes. Screenshot `/` on the seeded scratch server (both with and without a name set via the rename dialog on the scratch server).
