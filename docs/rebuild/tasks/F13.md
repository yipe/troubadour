# F13 · Facts (1k)

**Deps:** S5, C6 · **Size:** M · **Owns:** `web/app/src/pages/facts/`

## Read first
- `docs/design/troubadour-redesign/screenshots/1k-facts-table.png`, `docs/design/troubadour-redesign/Screen Facts A.dc.html`, README §1k. (1l and 1m are alternatives.)

## Build
- Rail 380px: `SearchInput` ("Search facts, names, quotes…") + primary "+ Add fact" (a `Dialog`: text, About (entity picker or Campaign), how sure; serial write). Grouped `NavItem` filters with counts: **About** (Everything, NPCs, Places, Items, Factions, PCs, Campaign), **How sure** (GM stated, Party theory, Heard once, with dots), **Said by** (per player, class-coloured dot, "Alex · GM and NPCs").
- Main: `PageHeading` "Facts", subtitle "389 things that stay true between sessions. Every one links to the moment it was said.", "Sort: newest session first" on the right; `FactsTable` of all confirmed facts (entities + campaign), filtered.
- Filters and search live in the query string (`?about=npc&sure=gm&by=<player_id>&q=`).
- A source opens the line (`TimestampLink`: audio, or the transcript at `?t=`).

## Tests
Counts per filter; combined filters; the URL holds the filters across a reload; search matches text, about and speaker; Add fact posts.

## Acceptance
- `pnpm -C web/app test typecheck` and `pnpm -C web lint build` pass; `yarn check` passes.
- `scripts/scratch.sh <PORT>`, then `pnpm -C web/app shot /facts /tmp/<ID>.png --port <PORT>`. Compare it with `docs/design/troubadour-redesign/screenshots/1k-facts-table.png` and fix layout, spacing, type and colour differences; list what's left in your report.
