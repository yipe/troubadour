## Changes
1. **Facts step** (`writeup.facts`): extend `FACTS_SCHEMA` items with `confidence` (enum gm/theory/once, same definitions as C4) and `replaces` (integer or -1). Prepend a "Known facts" block to the user message: facts already in the vault about names that appear in the notes, numbered, at most 40. `replaces` is the number of a known fact this one changes, or -1. Validate: an out-of-range number → -1; a missing or bad confidence → `"once"`. Keep the existing caps.
2. **Source line** (deterministic, `lore/writeup.py` `source_line(fact_text, about, aliases, lines)`): score each transcript line by IDF-weighted token overlap with the fact (reuse `ask.tokens`), with a bonus when the line names `about` or an alias. Ties go to the earlier line. A best score under a threshold (pick it from your test fixtures and document it) → no line. The result gives `source = {session_id, t: line.t_start}` and `said_by` = the line speaker's display name (the character name when spoken in character, else the player's). With no line, `source` is the session page only and `said_by` is null.
3. Write the suggestions as `Fact`s with `kind = "update"` and `replaces = <old text>` when it applies, otherwise `"new"`. The API's `FactSuggestion.replaces` is the old fact's **id**.
4. **Scenes**: after the notes step, one small extra LLM call (a new job step "Scenes", after the page step): given the numbered beats (`at` + text) and the campaign's Place names, return 3–8 scenes `{start: beat number, title: ≤ 8 words, place: a Place name or ""}`. Validate: starts strictly increasing and in range; the first scene starts at beat 1 (fix it if not); titles cleaned; `place` must be a known Place name or alias (else null). Store `sessions/<id>/scenes.json` as `[{t, title, place}]`, where `t` is the start beat's timestamp in seconds. If the call fails, store nothing; the write-up still succeeds.
5. `SavedSession.scenes` (`engine/_sessions.py`): read `scenes.json` → list or null.
6. Seed: `spike/seed/sessions.py` writes scenes for written-up sessions (S12: Table talk, Haggling with Orsa on the Gull's Debt, Saltreach docks at low tide, Entering the abbey, The bell chamber; places where it makes sense). `spike/seed/vault.py`: S12's suggested facts with sources, plus one update suggestion.
7. `@troubadour/api/sessions`: `Scene`, `SavedSession.scenes`.

## Tests (`test_writeup_sources.py`, `FakeLLM`)
- `source_line` picks the right line in a 30-line fixture, prefers a line naming `about`, and returns none under the threshold.
- Facts step: a confidence outside the enum → "once"; `replaces` 99 → -1; the "Known facts" block appears in the prompt and is capped at 40.
- The write-up job end to end with scripted LLM replies: suggestions carry sources; an update suggestion has `replaces`; `scenes.json` is written and validated (out-of-order starts are rejected, an unknown place → null); a failing scenes call still completes the job.
