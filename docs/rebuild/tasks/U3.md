## Build
- `Dialog` (base-ui): `DialogContent size="md"|"lg"` (640/900 px), `bg-surface border-line rounded-dialog shadow-popover`, overlay `rgba(10,11,16,.75)`. `DialogHeader` (title serif 20–22px, optional icon tile), `DialogBody`, `DialogFooter` (a muted note on the left, actions on the right).
- `ConfirmDialog`: `{ open, onOpenChange, title, body, confirmLabel, tone: "danger"|"primary", onConfirm }`. `onConfirm` may return a promise: the button shows a spinner and the dialog closes when it resolves. If it rejects, the dialog stays open with the error.
- `Popover`: `bg-popover border-popover-line rounded-dialog shadow-popover`. `Tooltip`: the same colours, 12px, `rounded-control`.
- `DropdownMenu` (base-ui Menu): items with an optional icon and a danger variant.
- `Command` (cmdk), restyled: used by the entity picker.
- `toast.tsx`: `Toaster` (sonner, bottom-centre, the tooltip look) and `notify(text, { undo?: () => void, tone?: "neutral"|"danger", duration? = 4000 })`. With `undo`, the toast shows an "Undo" action that calls it and closes the toast.
- `gallery/sections/overlays.tsx`: buttons that open each one.

## Tests (`overlays.test.tsx`)
- `ConfirmDialog`: confirm calls `onConfirm`; a rejected promise shows the error and keeps the dialog open.
- `notify` with `undo`: clicking "Undo" calls it once. Clear toasts between tests (`toast.dismiss()`).
