# R1 · Responsive layouts: wrap to two columns, then one

**Deps:** F24, F25 (runs after everything else, it touches many pages) · **Size:** L · **Owns:** see `dag.toml`

Owner request (2026-10-30): make the pages responsive. Multi-column layouts wrap to 2 columns, then 1, as
the window narrows, e.g. Home's three cards.

## Read first
- `web/packages/ui/src/components/rail-layout.tsx` (rail + main + optional right rail), `web/app/src/shell/` (top nav), and every page under `web/app/src/pages/`.
- `docs/rebuild/design-system.md` (spacing tokens). Tailwind v4 breakpoints: use `lg`/`xl`/`2xl` (and container queries where a card's width matters more than the window's).

## Steps
1. Breakpoints: ≥ 1280 px the design layouts as now; 768–1279 px two columns; < 768 px one column. Pick per page what drops first (usually the right rail moves under main, then the left rail becomes a top section or collapsible).
2. `RailLayout`: below `lg` the right rail stacks under the main column; below `md` the left rail stacks above (or collapses behind a "Show filters" toggle for list rails like Facts/Codex/Sessions). Keep each column independently scrollable only at desktop widths; when stacked, the page scrolls as one.
3. Grids: Home (3 cards → 2 → 1), Sessions detail stat tiles (5 → 3 → 2), Ready check, Settings sections (two-column → one), Recap (options + card), Timeline (table scrolls horizontally inside its card below `lg`; don't squash columns), Review (margin notes move under their line below `lg`), Live (notebook column becomes a tab/drawer below `lg`; never hide the transcript).
4. Top nav: tabs scroll horizontally or collapse into a menu below `md`; the right cluster keeps the recording pill and avatar.
5. No horizontal page scroll at 375 px on any route (except intentionally scrollable tables inside their card).

## Tests
- Browser tests (`*.browser.test.tsx`) for Home, Sessions, Facts and Live at 1440, 1024 and 390 px wide: assert column counts/stacking (bounding boxes) and that `document.documentElement.scrollWidth <= innerWidth`. Save `shot()`s.
- Keep existing tests green.

## Acceptance
`yarn check` passes. `smoke` at the default size stays clean. A screenshot set of every route at 1440/1024/390 (extend `scripts/smoke.ts` with a `--width` flag, owned here) reviewed by eye; list remaining issues in the report.
