## Build
`ImportNotes`: `{ onDone? }`, no dialog chrome. Title input (default "Imported notes") + a large `Textarea` to paste notes, or "Choose .md files" (multiple; concatenated with `# <file name>` headings). Import calls `useImportNotes`, then shows `JobStatus` for the job and, when done, chips for created, updated and suggested entries (each an `EntityLink`). Errors show inline. An empty text disables Import.

## Tests
Paste + Import posts the right body; the job's created names render as links; an empty paste keeps the button disabled.
