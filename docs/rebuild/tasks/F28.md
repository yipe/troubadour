# F28 · Ask: delete a past question

**Deps:** F17, C14 · **Size:** S · **Owns:** see `dag.toml`

Owner request (2026-10-30): on the Ask page's history, hovering a past question shows a small ✕ that
deletes it.

## Read first
- `backend/packages/lore/src/troubadour/lore/ask.py` (`Asker.answers`, `answers()` for the open campaign, `KEPT_ANSWERS`), `backend/packages/server/src/troubadour/server/routers/ask.py`.
- `web/packages/api/src/ask/` (endpoints, hooks), `web/packages/api/src/query/cache.ts` (`withAnswer`, campaign cache edits), `web/app/src/pages/ask/index.tsx` (+ test).

## Steps
1. Backend: `Asker.delete(answer_id)` removes an answer of the open campaign (KeyError → 404 for an unknown id or another campaign's). A running answer can be deleted too: when it finishes, it must not come back (drop late updates for deleted ids). Emit `campaign.updated` so other open windows refresh.
2. Route: `DELETE /api/campaign/answers/{answer_id}` (id pattern-checked) → 204. Add it to `tests/test_routes.py` (allowed minimal edit).
3. Web API: `deleteAnswer(id)` and `useDeleteAnswer()` in `@troubadour/api/ask`: optimistic removal from the campaign cache's `answers`, restored on error (use `useCampaignWrite`'s serial scope like the other campaign writes).
4. Ask page rail: each past question row shows an ✕ icon button on hover and on keyboard focus (`aria-label="Delete “<question>”"`, always visible on touch / coarse pointers). Deleting the selected answer selects the next newest (or the empty state). No confirm dialog; show `notify("Question deleted")` (no undo needed: the answer can simply be asked again).

## Tests
- Python: delete an answer; 404 for unknown and for another campaign's; a running answer deleted mid-way doesn't reappear when it completes.
- Web: the ✕ sends `DELETE`, the row disappears at once, comes back on a server error; deleting the selected one moves the selection.
