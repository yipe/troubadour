## Build (`lore/facts.py`; pure, no I/O)
```python
Confidence = Literal["gm", "theory", "once"]
LABELS = {"gm": "GM stated", "theory": "Party theory", "once": "Heard once"}

@dataclass
class Source:  session_page: str; session_id: str | None; t: float | None; label: str | None   # label "S12 1:38"
@dataclass
class Version: text: str; said_by: str | None; source: Source | None; confidence: Confidence
@dataclass
class Fact:
    text: str; about: str | None; said_by: str | None; source: Source | None
    confidence: Confidence = "once"; history: list[Version] = field(default_factory=list)
    replaces: str | None = None          # suggestions only: the old text ("→ replaces: …")
    @property
    def id(self) -> str: ...            # sha1(f"{about or ''}\n{norm(text)}")[:10]

def parse_bullets(lines: list[str], about: str | None) -> list[Fact]   # a "## Facts" section body
def render_bullets(facts: list[Fact]) -> list[str]
def parse_trailer(s: str) -> tuple[str, Source | None, str | None, Confidence | None]
def hms(t: float) -> str; def parse_hms(s: str) -> float | None        # "1:38:02"
```
- The trailer grammar is in the spec. Parse leniently, render canonically. The source label is `S<n> <h:mm>`
  and needs the session number, so `render_bullets` takes `numbers: dict[str, int]` (session id → n) and a
  `page_for: dict[str, str]` mapping ids to page names. When a fact's source has no session id, render the link
  as it was parsed.
- Old formats parse: a plain bullet; `text ([[Page]])`; anything else stays text (never drop a bullet). An
  unrecognised trailer stays part of the text.
- History: nested `  - ~~old~~ (trailer)` bullets after a fact belong to it.
- Round trip: `render(parse(x)) == x` for every canonical bullet, and for old-format bullets the text and source
  survive.
- `session_id` resolution: the page name → id map is passed in (`ids_for: dict[str, str]`); unknown → None.
