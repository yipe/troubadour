# Web workspace (pnpm: app, ui, api, tokens)

Run from `web/`. `pnpm install` once; `CI=true` needs `--no-frozen-lockfile` the first time.

| Task                                                                           | Command                                            |
| ------------------------------------------------------------------------------ | -------------------------------------------------- |
| Dev server (proxies `/api`, `/ws`, `/auth` to `TROUBADOUR_PORT`, default 8765) | `pnpm dev`                                         |
| Build to `web/dist` (served by the backend)                                    | `pnpm build`                                       |
| All tests, one vitest process, `TZ=UTC`                                        | `pnpm test`                                        |
| Types, lint, format                                                            | `pnpm typecheck`, `pnpm lint`, `pnpm format:check` |
| One package                                                                    | `pnpm -C packages/<pkg> test` / `typecheck`        |

## Layout

- `app/` `@troubadour/app`: routes, shell, pages. `packages/ui` `@troubadour/ui`: domain-free components.
  `packages/api` `@troubadour/api`: contract, HTTP, WebSocket, live store, query hooks.
  `packages/tokens` `@yipe/tokens`: colour tokens, copied from DPRcalc.
- `legacy/`: the old app, not in the workspace, not built, deleted by X2. Don't edit it.

## Rules (oxlint enforces the first four)

- `ui` never imports `@troubadour/api`. No `fetch` in `app/src` or `ui`: use a query hook.
- Pages don't import other pages (`@/pages/*`): promote shared code to `app/src/components`.
- Named exports only (config files and route modules' `Component` aside); no barrels.
- Only the dependencies already in the lockfile; none are added after W1.
- Never edit `packages/api/src/generated/` (generated by `pnpm gen`, git-ignored).
- Tests are deterministic: no network (`mockFetch`), `TZ=UTC`, explicit `en-US` formatting.
- Browsers are headless with `--mute-audio`; never play audio.
